Tools you can use

Tools are the capabilities agents call while they run. They are named in a workflow, take arguments from the calling agent’s instructions, and return typed, evidence-bearing output.

An agent gains a tool by being connected to a tool node whose config.tools lists it, through a tool_call edge. Each tool’s credentials come from your Settings at run time. See Set up your keys and data sources.

Fetch data

Section titled “Fetch data”

Acquire real market, macro, news, and social evidence.

ToolPurpose
fetch_exchange_dataMarket data: OHLCV candles, tickers, order books, trades, funding rates.
fetch_macro_dataMacro and alternative data: policy rates and economic indicators.
fetch_news_dataNews and filings: headlines and articles.
fetch_social_media_dataSocial posts, threads, and hashtag timelines.

A tool’s returned data_type is the source id and source type joined with an underscore (for example okx_ticker), which is what success rules match against. See Success rules.

Data analysis

Section titled “Data analysis”

Compute over fetched market data.

ToolPurpose
technical_analysisTechnical indicators (RSI, MACD, Bollinger Bands, ATR, VWAP, moving averages, and more).
quantitative_analysisStatistical metrics (alpha, beta, Sharpe, drawdown, correlation, and more).
signal_analysisHigher-level signal detection: patterns, threshold crossings, supports, divergence.
diagnostic_analysisDiagnostic checks over series.
detect_regimeRegime detection.
estimate_parametersParameter estimation.
simulate_processProcess simulation.
run_monte_carloMonte Carlo simulation.

Text analysis

Section titled “Text analysis”

Turn large amounts of text into structured, scored signal.

ToolPurpose
chunk_textChunk, window, deduplicate, and normalize large text.
semantic_searchRetrieve over stored data or documents.
extract_entitiesNamed-entity and relationship extraction (tickers, companies, people, dates).
classify_textClassify text into categories.
score_textScore sentiment, relevance, or credibility, per document and per entity.
summarize_textSingle-doc, multi-doc, and delta summarization.
cross_modal_alignmentAnchor text claims to fetched structured data.

Output

Section titled “Output”

Send results outside the workflow.

ToolPurpose
send_webhookPost to a webhook.
send_emailSend an email alert.
send_telegramSend a Telegram message.
write_outputStructured export or append to a dataset.

Tip

Split fetch and analysis onto separate tool nodes when different agents call them, for example a fetch node for the collector and a text-analysis node for the analyst, as in News and Social Pulse.
