This page explains how the system works at a high level, so you know what happens
when you press Run. For the exact parts you place on the canvas, see the
[building blocks](/reference/data-model/). For step-by-step tasks, see the
[how-to guides](/guides/use-an-example/).

## The parts

- **The canvas.** Where you design a workflow by dragging agents and tools and
  connecting them. It is also where you watch a run play out, with a live status
  on each node.
- **The workflow.** What the canvas produces: the agents, the tools they can use,
  the connections between them, and the rule each agent must satisfy to finish.
  This is the single source of truth. The canvas writes it, and the engine reads
  it.
- **The engine.** Reads the workflow and runs it. It works out the order of the
  steps, runs each agent, lets an agent call only the tools you connected, gathers
  the evidence, and checks each agent against its success rule.
- **Your model provider.** Every agent calls the model you chose, using the key you
  added in Settings. There is no shared, hidden model behind the scenes.

## What happens when you run

1. **Design.** You build or import a workflow on the canvas. When you save it, the
   app checks it and refuses to save one that is not sound, telling you why.
2. **Start.** You press Run. The work happens in the background, so the app stays
   responsive while a long workflow runs.
3. **Execute.** The engine runs each agent in order. For each one it gathers the
   right context, calls your model, lets the agent use its connected tools,
   collects the evidence, and checks it against its
   [success rule](/reference/completion-contracts/).
4. **Watch.** Each step streams to the canvas as it happens, so you see tool calls,
   retries, and output live, with a status on every node.

<Aside type="tip">
Because a run happens in the background, a long or expensive workflow never freezes the app. You keep browsing, and the run keeps streaming its progress.
</Aside>

## Bring your own model

Every run uses the provider key you set in Settings. If a run needs a key you have
not added, it says so plainly instead of quietly using someone else's. You choose
the model, and you never pay for anyone else's runs.
