This tutorial takes you from an empty app to a completed run in a few minutes.
You will import a working one-agent workflow, give it a model key, run it, and
read a market summary grounded in live exchange data.

You will use **Live Price Check**: one Market Analyst agent that fetches the
current Bitcoin price from OKX and writes a short, evidence-cited summary. OKX is
a public data source, so the only credential you need is one model provider key.

<Aside type="note">
Everything happens in the hosted app at <a href="https://app.traderai.tech">app.traderai.tech</a>. There is no install and no account to create. Your provider key is held for your session only and is not shared.
</Aside>

## Steps

<Steps>

1. **Open the app.** Go to <a href="https://app.traderai.tech">app.traderai.tech</a>.
   You land on the **Canvas** tab, with a **Schemas** panel on the left.

2. **Add a model provider key.** Open the **Settings** tab. Under LLM providers,
   find **OpenRouter**, paste your OpenRouter API key, and **Save**. The example
   runs on a Gemini model through OpenRouter, and you can change the model on each
   agent later.

   <Aside type="tip">
   No OpenRouter key? Any provider works. See [Set up your keys and data sources](/guides/configure-providers/). If you use a different provider, change the analyst's provider and model after importing (step 5).
   </Aside>

3. **Download the example.** Save
   [`simple_price_check.yaml`](/examples/simple_price_check.yaml) to your
   computer.

4. **Import it.** Back on the **Canvas** tab, click **Import YAML** on the
   Schemas panel and choose the file you just downloaded. The workflow loads onto
   the canvas: a **Market Analyst** agent wired to a **Fetch OKX** tool.

5. **Review the canvas.** Click the Market Analyst node to see its setup in the
   right-hand panel: its instructions, the price tool it is allowed to call, and
   the rule it must satisfy to finish. You do not need to change anything.

6. **Save.** Click **Save** on the Schemas panel. The workflow is now saved and
   appears in the schema list.

7. **Run.** With the workflow selected, click **Run**. The app switches to the
   **Runs** tab and starts streaming.

8. **Watch it execute.** On the run canvas, the Market Analyst turns blue while it
   works, then green when it finishes. The event feed shows the tool call, the
   price data it fetched, and the final output.

9. **Read the result.** The final message states the current Bitcoin last price,
   24-hour high, low, and volume, each citing the evidence it used in square
   brackets, for example `last 63,240 [e1]`.

</Steps>

## What just happened

The run succeeded only because it met the agent's **success rule**. Live Price
Check requires the analyst to actually collect the evidence, not just talk about
it:

- it must fetch the current price data, not describe it from memory;
- that data must include the last price and the 24-hour high, low, and volume;
- the final summary must cite its evidence and be a real summary, not one line.

If the model had written a summary without fetching the data, the evidence check
would have failed and the run would not be marked complete. This is the core idea
of the system: **success is gated on real evidence**, checked by machine, not on
plausible-sounding text.
